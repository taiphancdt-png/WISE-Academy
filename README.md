# WISE Academy — Website Portal

Website chính thức của **Viện Đào Tạo & Tư Vấn Quản Trị Tinh Gọn WISE Academy (Wisedemy)**.

Được phát triển trên nền tảng **Next.js 15 (App Router)**, **Tailwind CSS v4**, tối ưu hóa SEO và hiệu năng cao.

## 🚀 Tính Năng Chính
- **Trang chủ**: Giới thiệu giải pháp tinh gọn hiện trường, 6 bước PDCA thực tế, case study số liệu tăng trưởng, đội ngũ chuyên gia và form đặt lịch khảo sát.
- **Về chúng tôi (`/ve-chung-toi`)**: Tầm nhìn, sứ mệnh, triết lý đồng hành hiện trường.
- **Dịch vụ tư vấn (`/dich-vu-tu-van`)**: 4 trụ cột tư vấn đo lường năng suất, 5S, bảo trì TPM và số hóa.
- **Chương trình đào tạo (`/dao-tao`)**: 35+ chuyên đề đào tạo thực chiến may đo theo bối cảnh nhà máy.
- **Dự án thực tế (`/du-an`)**: Case study cấp tập đoàn (Pou Chen, GEODIS, Huali...) kèm hình ảnh khảo sát hiện trường.
- **Đội ngũ chuyên gia (`/chuyen-gia`)**: Đội ngũ chuyên gia từng điều hành các nhà máy lớn.
- **Góc tri thức (`/tri-thuc`)**: 26 bài viết chuyên sâu có mục lục tự động (TOC), hình ảnh sơ đồ phân tích và hướng dẫn thực tế.
- **Liên hệ (`/lien-he`)**: Đặt lịch tư vấn và khảo sát trực tiếp tại xưởng.

## 🛠️ Cài Đặt & Chạy Cục Bộ

```bash
# Cài đặt dependencies
npm install

# Chạy development server
npm run dev

# Build production
npm run build

# Khởi chạy production server
npm run start
```
